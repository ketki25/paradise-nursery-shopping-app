# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux Toolkit e-commerce application for browsing and purchasing houseplants.

## Features
- Landing page with a nursery introduction and Get Started button
- About Us page describing the company
- Three plant categories with six unique plants in each category
- Product thumbnails, names, descriptions, prices, and Add to Cart buttons
- Shared navigation bar with Home, Plants, and Cart links
- Dynamic cart item count
- Redux Toolkit cart state management
- Increase/decrease quantity, remove products, and calculate subtotals and grand total
- Checkout button with a Coming Soon message
- Continue Shopping navigation

## Run locally
1. Install Node.js (LTS).
2. Extract the project ZIP and open this folder in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (usually http://localhost:5173).

## GitHub submission
Create a public GitHub repository named `paradise-nursery-shopping-app`.
Upload the project files while preserving the folder structure. Then open each requested file on GitHub and copy its URL.

The assignment asks for direct URLs to:
- `README.md`
- `src/components/AboutUs.jsx`
- `src/App.css`
- `src/App.jsx`
- `src/redux/CartSlice.jsx`
- `src/components/ProductList.jsx`
- `src/components/CartItem.jsx`

Replace `YOUR_USERNAME` in the URL pattern with your GitHub username, for example:
`https://github.com/YOUR_USERNAME/paradise-nursery-shopping-app/blob/main/src/App.jsx`
